# KIMI Blog 2.2.1

- 所有客户端及安装到桌面的网页版统一使用用户提供的全新图标。

- 网页后台在同一个“评论”面板中提供评论删除、用户搜索、停用/恢复账号和昵称修改。
- 网页及 Android、Windows、iOS、Harmony 客户端支持长按本人评论确认删除，也提供可访问的删除按钮。
- 当前账号的评论优先显示；本人评论和其他评论分别按时间从新到旧排列。
- 评论与账号权限由同一个后端控制，进入页面及每 10 秒静默同步，保留评论草稿。
- 服务器检查删除权限；停用账号会使已有登录失效。删除操作需确认且不可撤销。
- 保留悬浮导航、文章卡片展开和阅读位置。

分发格式：Android 签名 APK、Windows 便携 EXE、iOS 源码 ZIP、HarmonyOS NEXT 源码 ZIP、OpenHarmony API 12 未签名开发 HAP。
iOS 需在 Xcode 使用自己的签名安装；OpenHarmony 开发包需设备签名，不能当成普通 HarmonyOS NEXT 安装包。
